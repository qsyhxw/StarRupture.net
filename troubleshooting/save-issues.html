StarRupture Save File Location & Recovery (PC/Steam)

Lost your progress? This guide covers where StarRupture stores save files, how to enable Steam Cloud sync, and steps to backup or recover your saves.

📂 Save File Locations

StarRupture saves are stored in two possible locations depending on your Steam Cloud settings.

Local Save Location

Your primary local save folder:

%LocalAppData%\StarRupture\Saved\SaveGames

Full path example:

C:\Users\YourUsername\AppData\Local\StarRupture\Saved\SaveGames
Quick Access: Press Win + R, paste %LocalAppData%\StarRupture\Saved\SaveGames, and press Enter.

Steam Cloud Save Location

If Steam Cloud is enabled:

C:\Program Files (x86)\Steam\userdata\[Your_Steam_ID]\1631270\remote\Saved\SaveGames

Note: 1631270 is StarRupture's Steam AppID. Replace [Your_Steam_ID] with your numeric Steam ID.

Save File Structure

File Type Description
.sav Main save data file
.met Metadata file (pairs with .sav)
AutoSave*.sav Automatic backup saves

💾 How to Backup Saves

Important: Always close StarRupture before copying or modifying save files to prevent corruption.
  1. Close StarRupture completely
  2. Navigate to your save folder (see paths above)
  3. Copy the entire SaveGames folder to a safe location (e.g., Desktop, external drive, cloud storage)
  4. Label the backup with the date (e.g., "StarRupture_Saves_2026-02-03")
Tip: Create backups before major game updates or when trying risky in-game actions.

☁️ Steam Cloud Sync

Steam Cloud automatically backs up your saves to Steam's servers, allowing you to access them from any PC.

Enable Steam Cloud

  1. Open Steam and go to Library
  2. Right-click StarRupture → Properties
  3. Go to the General tab
  4. Check "Keep games saves in the Steam Cloud for StarRupture"

Force Sync

If saves seem out of sync:

  1. Close StarRupture
  2. Right-click Steam tray icon → Exit Steam
  3. Restart Steam and launch the game
  4. Steam will sync the latest cloud save on startup

Steam Cloud Conflict

If Steam shows a sync conflict dialog:

  • Upload to Steam Cloud: Uses your local save (overwrites cloud)
  • Download to this machine: Uses cloud save (overwrites local)

Choose based on which save is more recent/valuable.

🔧 Troubleshooting Lost Saves

Save Not Appearing in Load Menu

  1. Check both local and Steam Cloud save locations
  2. Verify the .sav and matching .met files exist
  3. Ensure file names haven't been accidentally modified
  4. Try restarting the game and Steam

Corrupted Save (Game Won't Load It)

Warning: If the game prompts "Save file corrupt, delete?", do NOT confirm. Close the game first.
  1. Close the game without deleting
  2. Navigate to your save folder
  3. Check for AutoSave*.sav files—these may have a recent uncorrupted backup
  4. If you have a manual backup, replace the corrupted files with your backup
  5. Verify game files: Steam → Right-click StarRupture → Properties → Installed Files → Verify integrity

Progress Reset After Update

  1. Check if Steam Cloud sync was disabled or failed
  2. Look in both save locations—your old save may be in the other folder
  3. Check Steam Cloud storage online: https://store.steampowered.com/account/remotestorage (view only, can't download)

Transferring Saves to Another PC

  1. With Steam Cloud: Simply log in to Steam on the new PC and launch the game
  2. Without Steam Cloud:
    • Copy the SaveGames folder from the old PC
    • Paste it to the same location on the new PC
    • If save doesn't appear, create a new game with the same name, save it, then replace the files

❓ FAQ

Where is the AppData folder?

It's hidden by default. Press Win + R, type %LocalAppData%, and press Enter to open it directly.

How do I find my Steam ID?

Open Steam → Click your username (top right) → Account Details. Your Steam ID is a long number. Alternatively, check the userdata folder—each subfolder is a Steam ID.

Can I have multiple save files?

Yes, StarRupture supports multiple save slots. Each appears as a numbered folder or file within SaveGames.

Will verifying game files delete my saves?

No. "Verify integrity of game files" only checks game installation files, not your user data in AppData or Steam Cloud.

My autosaves are also corrupted. What now?

If you have no backup, recovery may not be possible. For future protection, enable Steam Cloud and make periodic manual backups.
