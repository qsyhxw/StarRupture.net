StarRupture Controls & Keybind Fixes (PC/Steam)

Keys not responding? Can't rebind? This guide covers StarRupture's default keybinds, how to customize controls, controller workarounds via Steam Input, and fixes for common input issues.

⚙️ How to Rebind Keys

  1. Open the game and press Esc to access the menu
  2. Navigate to Settings → Mouse & Keyboard
  3. Click on any action to rebind it to a new key
  4. Press the desired key when prompted
  5. Click Apply to save changes
Tip: You can also adjust mouse sensitivity, invert axes, and toggle Sprint/Crouch/ADS behavior (hold vs toggle) in the same menu.

🎮 Controller Support (Workaround)

As of version 0.1.3, StarRupture does not have native controller support on PC. However, you can use Steam Input to create a controller layout.

Setting Up Steam Input

  1. In Steam, right-click StarRupture → Properties
  2. Go to the Controller tab
  3. Set "Override for StarRupture" to Enable Steam Input
  4. Click Controller Layout to customize bindings
  5. Map controller buttons to keyboard keys (e.g., Right Trigger → Left Mouse Button)
Note: Community layouts may be available in Steam's controller configuration. Search for "StarRupture" layouts shared by other players.

Recommended Settings for Controller

  • Enable Toggle Sprint in Settings → Mouse & Keyboard
  • Enable Toggle ADS for easier aiming
  • Consider using gyro aiming (if your controller supports it) for precision

🔧 Common Issues & Fixes

Keys Not Responding

  1. Check for conflicting software: Close overlay apps (Discord, GeForce Experience, etc.)
  2. Run as Administrator: Right-click Steam → Run as administrator, then launch the game
  3. Verify game files: Steam → Library → Right-click StarRupture → Properties → Installed Files → Verify integrity
  4. Check keyboard language: Ensure Windows keyboard layout matches your physical keyboard
  5. Disable full-screen optimizations: Right-click StarRupture.exe → Properties → Compatibility → Check "Disable full-screen optimizations"

Stuck Inputs / Keys Repeating

  1. Alt+Tab out and back: This can reset stuck key states
  2. Check Sticky Keys: Press Shift 5 times quickly to access Sticky Keys settings, ensure it's disabled
  3. Restart the game: If inputs remain stuck, a full restart usually fixes it

Mouse Issues

  1. Raw input: Check if there's a raw mouse input option in settings
  2. Disable mouse acceleration: In Windows → Mouse settings → Additional mouse options → Pointer Options → Uncheck "Enhance pointer precision"
  3. Update mouse drivers: Check your mouse manufacturer's website for driver updates

❓ FAQ

Can I use a controller with StarRupture?

Not natively. Use Steam Input to map controller buttons to keyboard/mouse inputs. Community layouts may be available.

My keybinds reset after restarting. How do I fix this?

Check if your config file is set to read-only. Navigate to %LocalAppData%\StarRupture\Saved\Config\Windows and ensure GameUserSettings.ini is not read-only.

Some keys won't rebind. Is this a bug?

Some system keys (like Windows key) may be reserved. Try alternative keys. If a specific action won't rebind, report it via the game's feedback system.

How do I reset keybinds to default?

In Settings → Mouse & Keyboard, look for a "Reset to Defaults" button. If unavailable, delete the GameUserSettings.ini file (the game will regenerate it with defaults).
