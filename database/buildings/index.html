Processing Buildings

Refine raw materials into usable components and products.

Smelter

Processing

Output Rate
60/min (2s cycle)

Medium draw
Unlock
Selenian Lv1

Primary ore processing building. Converts raw Titanium, Wolfram, and Calcium ore into refined Bars and Blocks. Connect to Ore Excavators via rails for automated production chains.

Recipes Available

  • 2× Titanium Ore → 2× Titanium Bar (Default)
  • 2× Wolfram Ore → 2× Wolfram Bar (Default)
  • 2× Calcium Ore → 2× Calcium Block (Unlock: 1,000 Ca)
Selenian Corporation Level 1 (Default)

  • Titanium Sheets, Beams, Rods
  • Wolfram Plates, Wire

Building Tips

  • Power First: Always ensure adequate power before expanding
  • Plan Layouts: Leave space for rail connections and future expansion
  • Multiple Cores: Deploy additional Base Cores to expand build area
  • Defense Priority: Build turrets before Rupture events intensify
  • Automation Chain: Excavator → Smelter → Fabricator → Storage
